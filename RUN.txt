Swarm Assault 3D Redux - Windows x64

Double-click swarm_assault_3d.exe (keep the assets folder next to it).
The original game's art and sound (optional): press "Get the original art and sound" on the main
  menu to download them (20 MB, the archive OpenSA uses, kept on this PC only), or put your own copy
  of Swarm Assault in original_game\Swarm Assault inside this folder or the folder above, or set
  original_game_dir in assets\data\settings.ron. The game then uses its ground, interface, effects
  and sounds; nothing of it ships with this game.
Sound starts at volume 0: turn it up in Settings or with the in-game menu's slider.
Settings: assets\data\settings.ron   Controls: assets\data\controls.ron
Command line options: swarm_assault_3d.exe --help
Docs: README.md and docs\
Source code: https://github.com/mike70727/SwarmAssault3D_Redux (free software, GNU GPL version 3 or
  later: LICENSE). The Rust workspace is in source\ there; build it with
  cargo build --release -p swarm_assault_3d in source\ and start the game from the folder above it.
